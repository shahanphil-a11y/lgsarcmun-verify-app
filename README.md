# LGSARCMUN Hub

A dedicated Android companion app for the LGSARCMUN ecosystem — intentionally broader than QR verification.

## Roadmap
- QR membership scanning and verification
- Delegate/member directory (authorized access)
- Event check-in and attendance
- Conference schedule
- Committee and room information
- Announcements and notifications
- Digital membership cards
- Recent activity and scan history
- Admin tools and membership status management
- Offline-friendly event mode

The app uses the LGSARCMUN Supabase backend for authenticated data and verification services. It is separate from the public LGSARCMUN website.

## App identity
Product name: **LGSARCMUN Hub**

Do not call this app “Verify” in UI, package documentation, or future feature names. Verification is one feature of the larger app.
